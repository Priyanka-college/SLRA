📖 Overview

The Site Level Risk Assessment (SLRA) Tool is a web-based risk assessment application built using Flask (Python) and MySQL.
It helps organizations systematically identify, analyze, and manage workplace hazards by calculating Risk Priority Numbers (RPN) and classifying risks as Low, Medium, or High.

Designed for real-world use at construction sites, factories, and corporate environments, it simplifies risk management into a clean, data-driven web interface accessible from any device.
